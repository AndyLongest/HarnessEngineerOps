# Unit 4 交接模板

这些模板用于让当前会话的完成状态能被下一位 Agent 复核和接手。模板本身不是完成证据，必须填入真实命令、日志路径和判断结果。

## `session_exit_checklist.md`

```md
# 会话退出检查清单

- [ ] 构建或启动路径仍可用
- [ ] 必需测试通过
- [ ] 端到端或冒烟流程结果已记录
- [ ] feature_list 状态已更新并附证据
- [ ] PROGRESS.md 已更新
- [ ] 如果设计决策变化，DECISIONS.md 已更新
- [ ] Git diff 已保存，或明确说明本轮没有源码改动
- [ ] 没有遗留临时 debug 文件
- [ ] 没有新增注释掉的死代码
- [ ] 没有修改无关文件
- [ ] 下一步安全任务明确
```

## `handoff_protocol.md`

```md
# 交接协议

## 标记功能 passing 前
- 运行完成门禁。
- 运行仓库特定端到端路径。
- 保存验证日志。
- 更新 feature_list 证据。
- 完成 session_exit_checklist。
- 写入 handoff_report。

## 如果任一检查失败
- 不要标记为 passing。
- 保持状态为 active 或 blocked。
- 写入 Agent 可读错误消息。
- 记录下一步安全行动。

## 下一位 Agent 在没有口头背景时必须能找到的信息
- 功能状态。
- 证据路径。
- 已运行的命令/流程。
- 失败的检查。
- 清洁状态结果。
- 已知风险。
- 下一步安全任务。
- 禁止触碰区域。
```
