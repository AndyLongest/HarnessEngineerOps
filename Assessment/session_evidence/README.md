# Agent Evidence Assessment

A Codex skill for assessing what an individual learner demonstrates in AI-assisted work.

It starts from submitted Agent sessions, then uses qualitative analysis of outputs and reflections to corroborate, complement, or challenge session-based claims. It preserves learner attribution, observation opportunity, source provenance, and conflicts between evidence.

The skill is profile-driven. Supply an assessment profile that defines the target constructs, task knowledge, evidence thresholds, reporting rules, and any performance boundary. See the [profile contract](references/profile_contract.md).

The skill itself contains no course-specific rubric or student data. Its general workflow and supporting rules are in [SKILL.md](SKILL.md) and [references](references/).
