# Personal Assessment Report Contract

The report should be concise enough to use educationally but specific enough to audit.

## Required sections

### 1. Evidence coverage

Summarize:

- session sources;
- outputs/artifacts;
- reflections;
- assignment/scaffolds;
- missing or partial evidence;
- provenance concerns.

Include the supplied profile's task scope and a qualitative modality-selection record: source, content summary, selected constructs, evidence locators, and opportunity/coverage limits. Identify sessions as the primary assessment source for applicable constructs, and name any missing session coverage.

### 2. Construct summary

Use a table:

| Construct | Evidence strength | Confidence | Main basis | Main limitation |
|---|---|---|---|---|
| Profile construct | Strong/Moderate/Limited/Not established/Not observable/Conflicting | high/medium/low | ... | ... |

Do not convert these labels into an unrequested global numeric score.

Show how cross-modality triangulation affects the claims:

| Construct/claim | Provisional session finding and locator | Supplementary finding and locator | Relation | Final finding and reason for change |
|---|---|---|---|---|
| Applicable profile claim | Evidence strength and coverage | Selected supplementary evidence, if available | Corroboration/complement/contradiction/derivative/no relevant evidence | Strength, confidence, attribution and remaining limits |

Retain supplementary-only claims explicitly when no session evidence supports them. Report unresolved contradictions and avoid treating repetition as independent corroboration. Distinguish `not observable` from an applicable construct whose evidence is `not established`.

### 3. Profile-defined constructs

For each construct selected by the profile, report its operational definition, admissible evidence, attribution, opportunity/coverage, limiting evidence, and direct source pointers. Apply any profile-defined subcomponents separately. Where the profile includes an episode-based regulation construct, include a reconstructed episode when available:

`goal -> signal -> recognition/evaluation -> regulation -> follow-up`

### 4. Developmental pattern

Only when evidence permits, describe whether the submission shows a trajectory such as:

`applied knowledge -> practical feedback -> evidence-sensitive regulation -> emerging conditional judgment`

Use `consistent with` unless the temporal evidence truly shows formation over time.

### 5. Coursework rubric score (optional)

When requested, preserve the supplied rubric's exact item codes and scale.

For each item:

- score;
- direct evidence;
- why the next anchor is not met;
- distinguish missing submission evidence from inferred ability.

### 6. Most important next learning target

Give 1–2 targets that are:

- linked to the weakest *demonstrated evidence gap*, not generic advice;
- observable in a future session;
- achievable without assuming the learner lacks an ability merely because evidence was absent.

Example:

`When the Agent proposes a scope or verification strategy, explicitly state what task condition makes it appropriate and what evidence would make you change it.`

### 7. Performance handoff (optional)

Summarize task outcome evidence for a separate performance assessor:

- task;
- verified success/failure;
- unverified claims;
- test/runtime evidence;
- blockers;
- conditions.

## Language discipline

Prefer bounded conclusions:

- `In the supplied session...`
- `This demonstrates...`
- `This is suggestive of...`
- `The record does not establish...`
- `No clear opportunity was preserved to observe...`

Avoid stable-personality language unless repeated evidence across tasks supports it.
